# ВЕЛЕС · Брендбук «Легенды России»

Единый код коллекции: тёмный фон, золото, гравюрный герой в медальоне,
орнаментальный фриз региона, легенда на контрэтикетке.

## Состав
- `colors/` — палитра (CSS-переменные, JSON, Tailwind): мастер-код + 8 брендов
- `typography/` — роли шрифтов: Prata (дисплей), PT Serif (текст), PT Sans (служебный), Russo One (техно-бренды)
- `patterns/` — орнаментальные пояса: малахит (Урал), «бараньи рога» (Кавказ),
  петроглифы (Алтай), карельская вышивка (Сампо), улзы-меандр (Баргузин),
  северодвинская волна (Жива), неоновая хохлома (Жар-Птица)
- `symbols/` — знаки брендов: перо (Жар-Птица), ковш-утица (Жива), гора-лик (Хан-Алтай),
  жёрнов (Сампо), линии ветра (Баргузин), ящерка/пламя/полоз (Малахитница),
  чаша с огнём/голубка/меч (Нарт Санэ)
- `snippets/head.html` — подключение шрифтов

## Правила
1. Золото (#C99B45) — один акцент; всё остальное тихое.
2. Медальон — одна графическая единица на этикетке, без сюжетных сцен.
3. Дизайн-код 18+: гравюра, не мультяшность (алкоголь и энергетики).
4. Регион подписываем дескриптором «Легенды …» — топонимы не регистрируем.
