ПАРМА — файлы для 3D-печати

parma-butylka.stl   корпус, 60 x 60 x 310 мм, стенка 3 мм, дно вогнутое
parma-kryshka.stl   крышка, 35 x 35 x 24 мм, с накаткой

Геометрия у всех трёх вкусов одинаковая — печатается один корпус,
различаются только этикетка и цвет напитка.

Печать: файлы в миллиметрах, слайсер откроет их в натуральную величину.
Корпус — полая модель со стенкой 3 мм, поддержки нужны только под плечи.
Для прозрачного прототипа берите PETG и печатайте одним периметром
с нулевым заполнением: так стенка выйдет светопроводящей.
Крышка садится на горло диаметром 28 мм — при печати FDM заложите
зазор 0,2-0,3 мм на посадку.
